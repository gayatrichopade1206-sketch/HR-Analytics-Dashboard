 HR Analytics Dashboard

 📌 Project Overview
An interactive HR Analytics Dashboard created using Power BI and Excel to analyze employee data and provide business insights.

 🔧 Tools Used
- Power BI
- Microsoft Excel

 📊 Dashboard Features
- Employee Overview
- Attrition Analysis
- Department-wise Analysis
- Gender Distribution
- Age Group Analysis
- Interactive Slicers
- KPI Cards
